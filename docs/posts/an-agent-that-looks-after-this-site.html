I Built an Agent to Look After This Website

I built this site, and then I stopped using it. Every change meant opening a chat, explaining what I wanted, checking the result and pushing it live. I didn't want to keep doing that. So I built an agent whose whole job is this website.

What it does every morning

At about 7am, GitHub starts up a fresh machine, hands it this site and a written job description, and lets Claude get on with it. Each run, it:

  • checks every page for broken links, missing image descriptions and slow-loading photos, and fixes what it finds
  • looks in an "inbox" folder where I drop rough notes or photos, and turns them into posts or page updates
  • checks my Substack and YouTube for anything new and adds it here
  • makes one small design change, working down a list based on three personal websites I like

What it isn't allowed to do

It can only say things about me that I've written down for it. It can't delete posts, change the colours or fonts, or touch the code that builds the site. When it finishes, a separate safety check runs, one the agent can't skip. It undoes anything outside those limits and makes sure the site still builds. If it doesn't, nothing goes live that day.

My Instagram is a mix of personal posts and modelling work, so the agent never takes anything from it on its own. If I want something from there on the site, I put it in the inbox myself. That's my approval.

How I keep an eye on it

After every run it posts a short report on GitHub, which arrives as a notification on my phone: what it changed, with links to the pages. If I don't like something, I reply "undo" and the whole day is reversed. Or I say in a sentence what to undo, and only that part goes. Either way, it keeps a note of what I undid and doesn't do it again.

Its first night

I switched it on on a Sunday evening. In its first two runs it turned the line under my name into a proper hello, added the menu at the top of this page, and put my agency polaroids on the About page.

It also told me what it couldn't do. Substack turned it away, and it left some full-size photos behind that it wasn't allowed to delete. That's the part I like most: it says what went wrong instead of quietly carrying on.
