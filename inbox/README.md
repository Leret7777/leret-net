# Inbox

Drop things here for the site agent. No prompts needed: rough is fine.

- **Notes for a post**: a text file with bullet points, a voice-note
  transcript, a few lines about something you did. The agent turns it
  into a post in your voice the next morning, using only what you wrote.
  Start the first line with `commercial` or `modelling` if you want to
  choose the category.
- **Facts to update**: a line like "I'm now speaking at X" or "new
  role: Y". The agent updates the site and `agent/SOURCES.md`.
- **Instagram posts you approve for the site**: paste the post's link
  into a text file here (or save the photo/video into `inbox/photos/`).
  Only posts you put here are ever used; the agent never takes anything
  from Instagram by itself.
- **Your LinkedIn profile**: on LinkedIn, save your profile as a PDF
  and upload it here. The agent rewrites your About page from it.
- **Your LinkedIn posts**: paste them into a text file (one after
  another, with the date and link above each), or upload your LinkedIn
  data export. The agent adds one to the site each day.
- **Somewhere you've been featured**: a text file with the name of the
  magazine, brand or show, what it was (shoot, campaign, runway,
  interview), the month and year, and a link if there is one. Add a
  photo or the brand's logo if you have one. It goes on the Featured in
  page.
- **Photos**: put them in `inbox/photos/`. Add a text file next to them
  saying where they should go if it matters (e.g. "homepage photo,
  Manchester, Oct 2026").

Once the agent has used something, it moves it into `inbox/done/` so it
isn't used twice.
